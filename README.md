## 🚀 Features

- **ResNet18 classifier** converted from PyTorch to CoreML  
- **🎯 Predictions match PyTorch accuracy exactly**  
- **📸 Select any image from the device gallery**  
- **📊 Displays:**
  - Predicted ImageNet class label  
  - Confidence score (%)  
- **🔁 Full preprocessing (Resize → CenterCrop → Normalize) is embedded directly inside the CoreML model**
- **⚡ Fast on-device inference using Vision + CoreML**
- **🧠 Works fully offline – no API calls required**
- **📱 Clean and modern UIKit interface**
- **🧩 MVVM Architecture**
